# Mnema Atlas — Next-Phase Build Plan

_Generated by a 5-agent design pass (verified against the code), 2026-05-30._
Covers: (A) notes/flashcards separation, (B) graph polish, (C) AI docs + OpenAPI, (D) conversational-AI paste-import.

## ⚠️ Bug found during design
`cards.note_id` is `ON DELETE CASCADE` (`supabase/migrations/0001_init.sql:97`) → **deleting a note silently deletes its flashcards.** Fix: `ON DELETE SET NULL` (migration `0003`).

## Gating decisions (with recommendations)
- **D1 Notes↔Cards** — Separate the *sections* (nav/routes/managers) but **keep `cards.note_id` as a provenance backlink** (not a filing location). No breaking MCP/REST change; fixes the bug; enables "cards from this note" + "view source note in study". _Recommended._ (Alt: make cards fully independent, delete `note_id` — requires versioning the AI tool surface.)
- **D2 Paste format** — **JSON inside a ` ```mnema ` fence**. No YAML lib installed; `JSON.parse` is free; reuses zod schemas (zero drift). _Recommended._
- **D3 Graph library** — **Keep `react-force-graph-2d`, render fully custom on canvas, add `d3-force` (~20KB)** for radius-aware collision. _Recommended._
- **D4 Discovery endpoints** — `/openapi.json`, `/llms.txt`, `/.well-known/mnema`, `GET /`, `/healthz` stay **public/keyless**; only `/mcp` + `/rest/*` gated. _Recommended._

## Shared seams (land once)
- `shared/schemas.ts` is the hub: C's OpenAPI reads the 9 schemas; D appends `importPayload` (reuse `title`/`flashcardFace`).
- `src/lib/api.ts` + `src/lib/hooks.ts`: touched by A (`useCardsByNote`) and D (the **missing** `createFlashcardsBulk` wrapper). Sequence so the 2nd rebases cleanly.
- B is fully independent (`graph.tsx` + `index.css` tokens).

## Prioritized sequence
### Phase 0 — Foundations — S
- **0a** `0003` migration: `cards.note_id` CASCADE → SET NULL (the bug).
- **0b** add `createFlashcardsBulk` wrapper to `api.ts` (`created_via:'ui'`).
- **0c** `src/lib/endpoints.ts` constants (MCP/REST/OPENAPI from env, default `https://mnema-ai.dco.tw`); kill the stale `*.workers.dev` placeholder.

### Phase 1 — C: AI docs + OpenAPI — M — **build first**
- `worker/src/openapi.ts` `buildOpenApiSpec()` (pure fn over `tools`, 3.1.0).
- `worker/src/llms.ts` `buildLlmsTxt()`.
- `worker/src/discovery.ts` + `index.ts`: JSON `GET /` index, `/.well-known/mnema`, `Link`/`X-Mnema-Docs` headers, `WWW-Authenticate` on REST 401.
- Frontend `/settings/connect` (tabs: Claude Code / Cursor / ChatGPT-OpenAPI / curl) + `/settings/tools` (renders fetched `/openapi.json`).
- `api-keys.tsx` copy fixes.
- _Anti-drift: every artifact is a pure function of `tools.ts`._

### Phase 2 — A: Notes/Flashcards separation (Option B) — M
- `router.tsx` + `AppSidebar.tsx`: `/cards` "Flashcards" home.
- `src/routes/cards.tsx` (deck grid + all cards + due counts).
- `deck.tsx`: cards-only + per-card "from note" chip + edit.
- `note.tsx`: "Flashcards from this note" panel (`useCardsByNote`).
- `NewCardDialog.tsx`: deck picker.
- `api.ts`/`hooks.ts`: `listCardsByNote`/`useCardsByNote`.
- _Keep: "view source note" link on the Study answer side._

### Phase 3 — D: Paste-import bridge — M
- `shared/schemas.ts`: `importPayload`.
- `src/lib/import/parseMnema.ts` (+ tests): fence-extract → soft-repair (smart quotes, trailing commas) → zod → title→note-id resolution.
- `QuickImportDialog.tsx`: paste → live preview/diff → create.
- Entry points: `AppLayout`, `CommandPalette` ("Import from AI"), `AppSidebar`.
- _Keep: title-as-ref join (AI has no UUIDs); unknown-ref = warning; cap 200 to match bulk RPC._

### Phase 4 — B: Graph polish — L — parallelizable
- `useGraphTheme()` + OKLCH calm deck-color wheel (replaces saturated `PALETTE`).
- Layered `nodeCanvasObject` (shadow/halo/fill/rim), radius by degree, `nodePointerAreaPaint`.
- `linkCanvasObject`: curved, weight/type-aware, **directional gradient** (uses `weight`/`link_type`, currently discarded).
- Stroke-knockout labels.
- **Click-to-focus**: `focusId` + `activeSet` + dim-the-rest + HTML focus card + 2-click-to-open.
- `d3-force` tuning + `warmupTicks` (settle before paint), vignette, decorative empty state, skeleton loader.
- _Keep: fix the double-drawn node; directional gradient instead of arrowheads._

## Critical path
`0 → C → A → D`; **B runs in parallel** anytime. Recommended first move: **ship Phase 0 + Phase 1 (C) together.**
